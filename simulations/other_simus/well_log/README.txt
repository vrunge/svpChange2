WELL-LOG APPLICATION

This folder contains the real well-log application used in the SVP paper.
The script applies the Gaussian and robust/nonparametric SVP configurations,
plots the segmentation, and writes the paper figure.  SVP.pdf is the original
paper report/output associated with this analysis.

Run 4_well_log_application.R from the svpChange2 package root.  Input data are
read by the script as in the original paper workflow; inspect the script for
the expected data path before running on another machine.
