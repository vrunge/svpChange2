# Supporting and historical simulations

This folder contains studies that are not one of the six maintained primary
power/runtime workflows:

- `ar1_method_comparisons/`: diagnostic comparisons used while developing the
  AR(1) methods.
- `robust_validity_benchmark/`: the C++ validity-update microbenchmark.
- `smuce_comparison/`: SMUCE comparisons.
- `time_pruning/`: the four pruning-switch timing experiment.
- `well_log/`: the real-data well-log application.
- `maintenance/`: plot regeneration and calibration utilities.
- `time_gaussian_legacy/`: superseded Gaussian timing scripts and their
  historical outputs.
- `pre_refactor_power_results/`: power outputs generated before canonical
  method naming and before DeCAFS was added to the AR(1) study.

Maintained primary studies are documented in `simulations/README.md`.
