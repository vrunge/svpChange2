# AR(1) power study

Run from the `svpChange2` package root:

```r
Sys.setenv(SVP_RUN_SIMULATIONS = "true")
source("simulations/power_ar1/run_power.R")
```

On macOS/Linux the default uses all detected physical cores except one through
`parallel::mclapply()`. Set `run_and_save_ar1(workers = 1L)` for a sequential
run or pass another explicit worker count.

The maintained TRUE/TRUE AR1Focus constant is 4.5; see
`true_true_calibration.csv` for the historical calibration table. The
reported boundaries are the direct output of `SVP()`, without post-processing.
The final design uses 100 replications for each of the four patterns and 21
jump sizes from 1 to 5 in steps of 0.2, giving 8,400 simulated series and
42,000 method fits.

This clean study uses `n=600`, `rho=0.8`, marginal noise variance one, four
signal scenarios, jumps from 1 to 5 by 0.2, and 100 replications. AR(1) noise
is generated by `ts_generator()` with innovation standard deviation
`sqrt(1-rho^2)`. It compares inflated Gaussian PELT, PELT applied to the
transformed data `y[-1] - rho*y[-n]`, DeCAFS with its random-walk component
disabled (`sdEta=0`), AR1Focus SVP, and AR1Focus SVP with TRUE/TRUE pruning.
The transformed-data comparator calls the existing `PELT()` implementation;
it is approximate because the transformation does not represent the complete
exact AR(1) likelihood at every segment boundary.
The TRUE/TRUE method is the `SVP AR1Focus / both` configuration.
DeCAFS uses `4.75*log(n)`, the smallest multiplier attaining at least 95%
no-change recovery in an independent 1,000-replicate calibration. The
calibration is reproduced by `calibrate_decafs.R`, and its complete grid is
saved in `decafs_null_calibration.csv`. The null-versus-power comparison on
the complete study design is saved in `decafs_power_tradeoff.csv`. Relative
to the more conservative multiplier 6.25, multiplier 4.75 improves mean F1
from 0.809 to 0.833 for `up`, 0.555 to 0.635 for `updown`, and 0.680 to 0.722
for `rand1`, while retaining 95.4% correct no-change recovery on the study
samples. The pure AR(1) specification is
`sdEta=0`, `sdNu=sqrt(1-rho^2)`, and `phi=rho`.
The standard AR1Focus method uses `c = 3.75` with `subtests = "right"`; the
both-sided configuration uses `c = 4.5`.

The seven PDFs parallel the Gaussian and heavy-tail outputs. Changepoint
distributions use jump 1.4, which lies on the AR(1) simulation grid. The
algorithm checks and model-scale explanation are in `AR1_power_study.Rmd`.
