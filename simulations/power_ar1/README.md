# Corrected Section 5.3 AR(1) power study

Run from the `svpChange2` package root:

```r
source("simulations/power_ar1/calibrate_ar1.R")
calibration <- run_ar1_calibration(workers = 8L)
source("simulations/power_ar1/run_power.R")
run_and_save_ar1(workers = 8L, calibration = calibration)
source("simulations/power_ar1/export_paper_figures.R")
export_ar1_paper_figures(calibration = calibration)
```

The study follows Section 5.3 of `SVP_NEW.pdf`: `n=600`, `rho=0.8`, unit
stationary marginal variance, four signal patterns, jump sizes from 1 to 5 in
steps of 0.2, and 100 replications. AR(1) data are generated by
`ts_generator(type = "gaussAR1")` with innovation standard deviation
`sqrt(1-rho^2)`.

The four algorithms are `PELT AR1 approximate`, `PELT inflated`, `DeCAFS AR1`,
and `SVP AR1Focus / right`. The approximate PELT method applies PELT to
`y[-1] - rho*y[-n]`, maps transformed endpoints back to the original series,
and uses a calibrated penalty `c_P*log(n)`. The inflated PELT baseline remains
fixed at `3*log(n)*(1+rho)/(1-rho)`.

DeCAFS is calibrated to corrected null F1 at least 0.99. The approximate PELT
penalty and SVP AR1Focus threshold are selected to match the selected DeCAFS
null F1. Calibration uses 1,000 null series and validation uses 1,000
independent null series, with deterministic seeds and Wilson intervals.

All metrics use `simulations/power_common.R`: endpoint `n` is excluded,
matches are one-to-one within a five-observation tolerance, and the output
contains precision, recall, F1, correct-number probability, MSE, segment count,
and localization error.

The full study has `4*21*100*4 = 33,600` method rows. Previous outputs are
preserved in `simulations/other_simus/power_ar1_legacy_20260915/`.
